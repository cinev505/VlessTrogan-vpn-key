#  Против блокировок & тгк: VlessTrogan 

Набор актуальных конфигураций для обхода блокировок с использованием протоколов VLESS,Trojan и Shadowsocks

## Инструкция по подключению

###  Husi / Nekobox / Exclave 
1. Нажмите на иконку "+" в верхнем правом углу.
2. Выберите пункт "Импорт из буфера обмена"
3. После этого добавятся группы,нажмите на 3 точки и выберите "URL Тест"
4. Когда закончилось: 3 точки "Удалить недоступные" и там же "Сортировка-По задержке" Готово!

### Karing 
1. Найдите колёсико в левом верхнем углу,
пролистайте до параметра "Добавить профиль"
2. И нажмите "Импорт из буфера обмена"
3. В примечание вставьте ссылку.
4. Вернитесь на главный экран и нажмите на щит.
